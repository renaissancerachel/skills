# Personalize deep-doc-authoring

This file binds the generic roles in `SKILL.md` and the task files to your actual setup. `personal.md`
is yours; keep it out of any shared repo (gitignore it). This `PERSONALIZE.template.md` ships with the
skill; `personal.md` does not.

**Two ways to fill it:** copy this file to `personal.md` in this folder and fill the fields yourself,
or let the agent write it for you.

**Agent — interviewing to fill this (Step 1 of `SKILL.md`, when no `personal.md` exists):** ask for
each field below one topic at a time, in a conversational back-and-forth — the same expansive stance
as [`references/brainstorm.md`](references/brainstorm.md) (draw them out; don't demand crisp answers).
When you have enough, write their answers to `personal.md` and confirm it back. This is a one-time
setup; after it, the skill is theirs.
